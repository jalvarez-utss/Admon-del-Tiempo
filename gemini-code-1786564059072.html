El Método ABC de Lakein (1973)
A

Alta Prioridad: Tareas más valiosas e importantes con consecuencias significativas si no se realizan. (Regla: Nunca realizar una B o C teniendo una A pendiente).

B

Prioridad Media: Tareas importantes, pero con consecuencias menores si sufren un retraso moderado.

C

Baja Prioridad: Actividades de escaso valor que podrían eliminarse o delegarse sin mayor impacto en las metas.
